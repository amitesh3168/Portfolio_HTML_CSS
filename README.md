# Developer Portfolio — Amitesh Shukla

A modern, high-performance developer portfolio website designed with a dark crimson theme, glowing neon accents, and smooth CSS-only micro-animations.

---

## Features

- **Dark & Crimson Aesthetic**: Sleek slate-dark palette (`#08080a`) highlighted with energetic crimson red (`#ff2d55`) accents and dynamic drop glows.
- **Interactive Avatar Frame**: Circular profile photo wrapper featuring an animated 360° rotating conic-gradient glow ring and floating motion.
- **Project Showcase**: Highlights major systems with tech stacks, core features, and live links:
  - *Pipeline Sentinel*: CI/CD Failure Analysis & Prediction Platform[cite: 1]
  - *SmartSQL*: Natural Language Interface for SQL Databases[cite: 1]
  - *AI Full-Stack Website Builder*: Prompt-to-web generator[cite: 1]
- **Skills Architecture**: Organized breakdown for Programming Languages, Frontend, Backend, Databases, and AI Frameworks[cite: 1].
- **Career & Education Timeline**: Chronological track record including NIET B.Tech details, hackathon achievements, and certifications[cite: 1].
- **Zero External JS Dependencies**: Built strictly using pure HTML5 and vanilla CSS3 for instant load speeds.
- **Fully Responsive**: Adapts across mobile, tablet, and desktop viewports.
